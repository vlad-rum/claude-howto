# Глоссарий и стиль перевода

> Этот документ задаёт единые правила русского перевода руководства Claude How-To. Источник истины — английские файлы в корне репозитория. Перевод лежит в `ru/` и повторяет структуру `uk/`.

## Правила

1. Код, команды оболочки, флаги CLI, пути, ключи JSON/YAML, имена полей frontmatter, URL и имена слэш-команд остаются на английском.
2. Переводятся проза, заголовки, текст таблиц, подписи в диаграммах Mermaid, комментарии в коде и человекочитаемые значения frontmatter (например, `description`).
3. В `description` сохраняется английская пометка `Use PROACTIVELY`, если она есть в оригинале: по ней Claude Code решает, вызывать ли субагента.
4. Обращение к читателю — **вы** (со строчной буквы).
5. Буква **ё** пишется. Кавычки в тексте — «ёлочки».
6. Относительные ссылки внутри `ru/` ведут на русские файлы. Картинки из `resources/` ссылаются на общий каталог уровнем выше (`../resources/...`).
7. Якоря совпадают с переведёнными заголовками (правила слагов GitHub, кириллица сохраняется).
8. В каждом переведённом файле в начале стоят комментарии версии оригинала:

```markdown
<!-- i18n-source: 01-slash-commands/README.md -->
<!-- i18n-source-sha: a1b2c3d4 -->
<!-- i18n-date: 2026-10-23 -->
```

## Диаграммы Mermaid

Подписи узлов, рёбер и сообщения sequence-диаграмм переводятся. Идентификаторы узлов и синтаксис не меняются. Подписи со спецсимволами заключаются в двойные кавычки: `A["Ввод пользователя"]`. Комментарии Mermaid — только `%%`.

## Стиль

Живой технический русский без канцелярита: «запустите», а не «осуществите запуск». Аббревиатуры API, CLI, CI/CD, MCP, PR не склоняются и раскрываются при первом упоминании в файле, если это делает оригинал.
