# Настройка пайплайна CI/CD

Внедрите комплексные проверки качества DevOps с учётом типа проекта:

1. **Проанализируйте проект**: определите язык(и), фреймворк, систему сборки и уже имеющиеся инструменты
2. **Настройте хуки pre-commit** инструментами под конкретный язык:
   - Форматирование: Prettier/Black/gofmt/rustfmt/и т. д.
   - Линтинг: ESLint/Ruff/golangci-lint/Clippy/и т. д.
   - Безопасность: Bandit/gosec/cargo-audit/npm audit/и т. д.
   - Проверка типов: TypeScript/mypy/flow (если применимо)
   - Тесты: запуск подходящих наборов тестов
3. **Создайте рабочие процессы GitHub Actions** (.github/workflows/):
   - Повторите проверки pre-commit на push и PR
   - Матрица версий и платформ (если применимо)
   - Проверка сборки и тестов
   - Шаги деплоя (если нужны)
4. **Проверьте пайплайн**: протестируйте локально, создайте тестовый PR, убедитесь, что все проверки проходят

Используйте бесплатные инструменты с открытым исходным кодом. Сохраняйте существующие конфигурации. Держите выполнение быстрым.
