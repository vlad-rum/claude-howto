# Расширение модульных тестов

Расширьте существующие модульные тесты с учётом тестового фреймворка проекта:

1. **Проанализируйте покрытие**: запустите отчёт о покрытии, чтобы найти непокрытые ветки, граничные случаи и области с низким покрытием
2. **Найдите пробелы**: просмотрите код на логические ветки, пути ошибок, граничные условия, пустые входы и null
3. **Напишите тесты** на фреймворке проекта:
   - Jest/Vitest/Mocha (JavaScript/TypeScript)
   - pytest/unittest (Python)
   - Go testing/testify (Go)
   - тестовый фреймворк Rust (Rust)
4. **Целевые сценарии**:
   - Обработка ошибок и исключения
   - Граничные значения (min/max, пусто, null)
   - Граничные и угловые случаи
   - Переходы состояний и побочные эффекты
5. **Проверьте улучшение**: снова запустите покрытие и подтвердите измеримый рост

Покажите только новые блоки тестового кода. Следуйте существующим шаблонам тестов и соглашениям об именовании.
