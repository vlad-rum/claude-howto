# Синхронизация документации

Синхронизируйте документацию с кодовой базой:

1. Обнаружьте изменения кода
2. Найдите устаревшую документацию
3. Обновите затронутые документы
4. Проверьте, что примеры всё ещё работают
5. Обновите номера версий
