# Генератор документации API

Сгенерируйте полную документацию API:

1. Просканируйте эндпоинты API
2. Извлеките сигнатуры функций и JSDoc
3. Сгруппируйте по модулю или эндпоинту
4. Создайте Markdown с примерами
5. Включите схемы запроса и ответа
6. Добавьте документацию ошибок
