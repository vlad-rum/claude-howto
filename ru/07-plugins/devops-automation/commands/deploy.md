# Деплой приложения

Выполните рабочий процесс деплоя:

1. Запустите проверки перед деплоем
2. Соберите приложение
3. Запустите тесты
4. Задеплойте в целевое окружение
5. Запустите проверки здоровья
6. Уведомите команду в Slack
