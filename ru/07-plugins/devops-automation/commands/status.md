# Проверка статуса системы

Проверьте здоровье системы по всем сервисам:

1. Запросите статус подов Kubernetes
2. Проверьте подключения к базе данных
3. Отследите время ответа API
4. Просмотрите частоту ошибок
5. Проверьте использование ресурсов
6. Сообщите об общем здоровье
