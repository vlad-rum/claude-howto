# Реагирование на инцидент

Структурированный рабочий процесс реагирования на инцидент:

1. Создайте запись инцидента
2. Оцените серьёзность и влияние
3. Уведомите дежурную команду
4. Соберите диагностическую информацию
5. Скоординируйте усилия по реагированию
6. Задокументируйте устранение
7. Запланируйте постмортем
