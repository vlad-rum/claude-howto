# Проверка покрытия тестами

Проанализируйте покрытие тестами и их качество:

1. Проверьте процент покрытия тестами
2. Найдите непокрытые пути кода
3. Оцените качество тестов
4. Предложите недостающие тест-кейсы
5. Проверьте, что граничные случаи покрыты
