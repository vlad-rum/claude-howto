# Claude How To — бренд-материалы

Полный набор логотипов, значков и фавиконок проекта Claude How To. Все материалы используют дизайн V3.0: компас со скобкой кода (`>`), путь по коду с проводником — палитра чёрный/белый/серый с ярко-зелёным акцентом (#22C55E).


## Обзор материалов

### Концепция дизайна (V3.0)

**Компас со скобкой кода** — проводник встречается с кодом:
- **Кольцо компаса** = навигация, поиск пути
- **Северная стрелка (зелёная)** = направление, прогресс на учебном пути
- **Южная стрелка (чёрная)** = опора, твёрдое основание
- **Скобка `>`** = приглашение терминала, код, контекст CLI
- **Засечки** = точность, структурированное обучение

### Логотипы

**Файлы**:
- `logos/claude-howto-logo.svg` (светлая тема)
- `logos/claude-howto-logo-dark.svg` (тёмная тема)

**Параметры**:
- **Размер**: 520×120 px
- **Назначение**: главный логотип шапки и бренда со словесным знаком
- **Применение**:
  - Шапки сайтов
  - Значки README
  - Маркетинговые материалы
  - Печатные материалы
- **Формат**: SVG (полностью масштабируется)
- **Темы**: светлая (белый фон) и тёмная (фон #0A0A0A)

### Значки

**Файлы**:
- `icons/claude-howto-icon.svg` (светлая тема)
- `icons/claude-howto-icon-dark.svg` (тёмная тема)

**Параметры**:
- **Размер**: 256×256 px
- **Назначение**: значок приложения, аватары, миниатюры
- **Применение**:
  - Значки приложений
  - Аватары профиля
  - Миниатюры для социальных сетей
  - Шапки документации
- **Формат**: SVG (полностью масштабируется)
- **Темы**: светлая (белый фон) и тёмная (фон #0A0A0A)

**Элементы дизайна**:
- Кольцо компаса с засечками сторон света и промежуточными засечками
- Зелёная северная стрелка (направление и проводник)
- Чёрная южная стрелка (основание)
- Скобка кода `>` в центре (терминал и CLI)
- Зелёная центральная точка как акцент

### Фавиконки

Оптимизированные версии нескольких размеров для веба:

| Файл | Размер | DPI | Применение |
|------|------|-----|-------|
| `favicon-16.svg` | 16×16 px | 1x | Вкладки браузера (старые браузеры) |
| `favicon-32.svg` | 32×32 px | 1x | Обычная фавиконка браузера |
| `favicon-64.svg` | 64×64 px | 1x-2x | Экраны с высоким DPI |
| `favicon-128.svg` | 128×128 px | 2x | Значок Apple touch, закладки |
| `favicon-256.svg` | 256×256 px | 4x | Современные браузеры, значки PWA |

**Заметки по оптимизации**:
- 16px: минимум геометрии — только кольцо, стрелки и шеврон
- 32px: добавляются засечки сторон света
- 64px+: полная детализация с промежуточными засечками
- Все сохраняют зрительное единство с основным значком
- Формат SVG даёт чёткую картинку при любом размере

## Цветовая палитра

### Основные цвета
- **Чёрный**: `#000000` (основной текст, обводки, южная стрелка)
- **Белый**: `#FFFFFF` (светлые фоны)
- **Серый**: `#6B7280` (вторичный текст, мелкие засечки)

### Акцентный цвет
- **Ярко-зелёный**: `#22C55E` (северная стрелка, центральная точка, акцентные линии — только выделения, никогда как фон)

### Тёмная тема
- **Фон**: `#0A0A0A` (почти чёрный)

### Переменные CSS
```css
--color-primary: #000000;
--color-secondary: #6B7280;
--color-accent: #22C55E;
--color-bg-light: #FFFFFF;
--color-bg-dark: #0A0A0A;
```

### Конфигурация Tailwind
```js
colors: {
  brand: {
    primary: '#000000',
    secondary: '#6B7280',
    accent: '#22C55E',
  }
}
```

### Правила применения
- Чёрный — для основного текста и конструктивных элементов
- Серый — для вторичных и поддерживающих элементов
- Зелёный **только** для выделений: стрелка, точки, акцентные линии
- Никогда не используйте зелёный как цвет фона
- Держите контраст WCAG AA (минимум 4.5:1)

## Правила дизайна

### Использование логотипа
- Ставьте на белый или тёмный (#0A0A0A) фон
- Масштабируйте пропорционально
- Оставляйте свободное место вокруг логотипа (минимум: высота логотипа / 2)
- Для подходящего фона берите готовые светлый и тёмный варианты

### Использование значка
- Используйте стандартные размеры: 16, 32, 64, 128, 256px
- Сохраняйте пропорции компаса
- Масштабируйте пропорционально

### Использование фавиконки
- Берите размер под контекст
- 16–32px: вкладки браузера, закладки
- 64px: значки сайта
- 128px+: домашние экраны Apple и Android

## Оптимизация SVG

Все файлы SVG — плоский дизайн без градиентов и фильтров:
- Чистая геометрия на обводках
- Без встроенных растров
- Оптимизированные пути
- Отзывчивый viewBox

Для оптимизации под веб:
```bash
# Сжать SVG, сохранив качество
svgo --config='{
  "js2svg": {
    "indent": 2
  },
  "plugins": [
    "convertStyleToAttrs",
    "removeRasterImages"
  ]
}' input.svg -o output.svg
```

## Преобразование в PNG

Чтобы преобразовать SVG в PNG для старых браузеров:

```bash
# С помощью ImageMagick
convert -density 300 -background none favicon-256.svg favicon-256.png

# С помощью Inkscape
inkscape -D -z --file=favicon-256.svg --export-png=favicon-256.png
```

## Доступность

- Высокие коэффициенты контраста (соответствует WCAG AA — минимум 4.5:1)

- В значках нет текста (текст отдельно, в словесном знаке)
- Смысл не зависит от пары красный–зелёный
