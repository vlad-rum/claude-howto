# Claude How To — система дизайна

## Визуальная идентичность

### Концепция значка: компас со скобкой кода

Значок Claude How To — это **компас со скобкой кода `>`**: он означает путь по коду с проводником:

```
     N (зелёный)
     ▲
     │
W ───>─── E     Компас = ориентир/направление
     │          Скобка > = код/терминал/CLI
     ▼
     S (чёрный)
```

Это даёт:
- **Зрительная ясность**: сразу читается как «проводник по коду»
- **Символический смысл**: компас — найти путь; `>` — код и терминал
- **Масштаб**: работает при любом размере от 16px до 512px
- **Согласованность с брендом**: эстетика инструмента разработчика и скупая палитра

## Цветовая система

### Палитра

| Цвет | Hex | RGB | Применение |
|-------|-----|-----|-------|
| Чёрный (основной) | `#000000` | 0, 0, 0 | Основные обводки, текст, южная стрелка |
| Белый (фон) | `#FFFFFF` | 255, 255, 255 | Светлые фоны |
| Серый (вторичный) | `#6B7280` | 107, 114, 128 | Мелкие засечки, вторичный текст |
| Ярко-зелёный (акцент) | `#22C55E` | 34, 197, 94 | Северная стрелка, центральная точка, акцентные линии |
| Почти чёрный (тёмный фон) | `#0A0A0A` | 10, 10, 10 | Фоны тёмной темы |

### Коэффициенты контраста (WCAG)

- Чёрный на белом: **21:1** AAA
- Серый на белом: **4.6:1** AA
- Зелёный на белом: **3.2:1** (только декоративный, не для текста)
- Белый на тёмном: **19.5:1** AAA

### Правило акцентного цвета

**Ярко-зелёный (#22C55E) только для выделений:**
- Северная стрелка компаса
- Центральная точка
- Акцентные подчёркивания и рамки
- Никогда как цвет фона
- Никогда для основного текста

## Детали значка

### Параметры компаса

Знак компаса собран из таких геометрических элементов:

```
Элемент                  | Обводка/заливка | Цвет
-------------------------|-----------------|------------------------------
Внешнее кольцо           | обводка 3px     | Чёрный / белый (тёмная тема)
Северная засечка         | обводка 2.5px   | Чёрный / белый (тёмная тема)
Прочие засечки сторон    | обводка 2px     | Серый / белый 50% (тёмная тема)
Промежуточные засечки    | обводка 1.5px   | Серый / белый 40% (тёмная тема)
Северная стрелка         | залитый полигон | #22C55E (всегда зелёная)
Южная стрелка            | залитый полигон | Чёрный / белый (тёмная тема)
Скобка >                 | обводка 3px     | Чёрный / белый (тёмная тема)
Центральная точка        | залитый круг    | #22C55E (всегда зелёная)
```

### Нарастание детализации по размеру

```
16px  → только кольцо, стрелки и шеврон (минимум)
32px  → добавляются засечки сторон света
64px  → добавляются промежуточные засечки
128px → полная детализация, все элементы чёткие
256px → максимум деталей, толстые обводки
```

## Правила размеров

### Размер логотипа

- **Минимум**: ширина 200px (для веба)
- **Рекомендуется**: 520px (исходный размер)
- **Максимум**: без ограничений (вектор)
- **Пропорции**: ~4.3:1 (ширина:высота)

### Размер значка

- **Минимум**: 16px (фавиконка)
- **Рекомендуется**: 64–256px (приложения, аватары)
- **Максимум**: без ограничений (вектор)
- **Пропорции**: 1:1 (квадрат)

- Весь текст соответствует WCAG AA (минимум 4.5:1)

## Подробности формата файлов

### Структура SVG

Все файлы SVG — плоский дизайн:
- Без градиентов (только сплошные цвета)
- Без эффектов фильтров (без размытия, свечения и тени)
- Чистая геометрия обводки и заливки
- ViewBox для отзывчивого масштаба
- Читаемый код с комментариями

### Совместимость браузеров

- Chrome/Edge: полная поддержка
- Firefox: полная поддержка
- Safari: полная поддержка
- iOS Safari: полная поддержка
- Все современные браузеры: полная поддержка

## Настройка

### Смена акцентного цвета

Чтобы сделать вариант с другим акцентом:

1. Замените все вхождения `#22C55E` на свой акцентный цвет
2. Для декоративных элементов держите контраст выше 3:1
3. Структуру чёрного, белого и серого не меняйте

### Масштабирование

```css
svg {
  width: 256px;
  height: 256px;
}
```

SVG масштабируются сами через viewBox — трансформации не нужны.
