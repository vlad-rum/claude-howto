## Слэш-команды

Команды — это сокращения, которые вызывает пользователь и которые выполняют конкретные действия.

## Режимы разрешений

Claude Code поддерживает 6 режимов разрешений, которые определяют, как авторизуется использование инструментов.

| Режим | Описание | Когда использовать |
|------|-------------|-------------|
| `manual` | Запрос на каждый вызов инструмента | Когда вы сами проверяете каждое действие (с v2.1.200 отображается как Manual; значение в конфигурации по-прежнему `default`, `manual` — псевдоним). С v2.1.283 auto — встроенный стартовый режим для интерактивных сессий в терминале и VS Code |
| `acceptEdits` | Автоматически принимать правки файлов, спрашивать об остальном | Доверенные рабочие процессы редактирования |
| `plan` | Исследовать и предложить план; правок исходников нет, пока вы его не одобрите | Планирование и исследование |
| `auto` | Все действия, с фоновыми проверками классификатора безопасности | Долгие задачи, меньше усталости от запросов |
| `bypassPermissions` | Пропустить все проверки разрешений | CI/CD, окружения headless |
| `dontAsk` | Пропускать инструменты, которым нужно разрешение | Неинтерактивные скрипты |

> **Примечание**: режим `auto` требует подходящего плана, модели и провайдера — см. [09-advanced-features/](09-advanced-features#auto-mode). Используйте `bypassPermissions` только в доверенных окружениях с песочницей.

**Справочник**: [Официальная документация](https://code.claude.com/docs/en/permissions)

## Субагенты

Специализированные ИИ-помощники с изолированным контекстом для конкретных задач.

> **Вложенный запуск включён по умолчанию, глубина 3 (v2.1.219)**: субагенты могут запускать своих субагентов до трёх уровней ниже основного разговора. Задайте `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`, чтобы изменить предел, или `1`, чтобы отключить вложенность. (История: в v2.1.172–v2.1.216 вложенность была по умолчанию до 5 уровней, и изменить это было нельзя; в v2.1.217 вложенность стала явной на глубине 1; в v2.1.219 значение по умолчанию стало 3.) См. [04-subagents/README.md](04-subagents/README.md#ограничение-запускаемых-субагентов) про синтаксис `Agent(agent_type)`, который ограничивает, каких субагентов может запустить данный субагент.

### Встроенные субагенты

| Агент | Описание | Инструменты | Модель | Когда использовать |
|-------|-------------|-------|-------|-------------|
| **general-purpose** | Многошаговые задачи, исследование | Все инструменты | Наследует модель | Сложное исследование, задачи на много файлов |
| **Plan** | Планирование реализации | Read, Glob, Grep, Bash | Наследует модель | Проектирование архитектуры, планирование |
| **Explore** | Исследование кодовой базы | Read, Glob, Grep | Наследует (потолок — Opus) | Быстрый поиск, понимание кода |
| **claude** | Запасной вариант для задач, которым не подходит более специализированный агент | Все инструменты | Наследует модель | Задачи без специализированного агента; агент по умолчанию для отправленной фоновой сессии |
| **statusline-setup** | Настройка строки состояния | Bash, Read, Write | Sonnet | Настроить отображение строки состояния |
| **claude-code-guide** | Справка и документация | Read, Glob, Grep | Haiku | Получить помощь, изучить функции |

### Поля конфигурации субагента

| Поле | Тип | Описание |
|-------|------|-------------|
| `name` | строка | Идентификатор агента |
| `description` | строка | Что делает агент |
| `model` | строка | Переопределение модели (`sonnet`, `opus`, `haiku`, `fable`, полный ID модели или `inherit`) |
| `tools` | массив | Список разрешённых инструментов |
| `effort` | строка | Уровень усилий (`low`, `medium`, `high`, `xhigh`, `max`; зависит от модели) |
| `initialPrompt` | строка | Первый ход пользователя, который отправляется сам, когда агент работает как агент основной сессии (`--agent`) |
| `disallowedTools` | массив | Инструменты, явно запрещённые этому агенту |

| Сервер | Описание | Когда использовать | Область | Установка |

| **База данных** | SQL-запросы, доступ к данным | Операции с базой данных | Локальная | `claude mcp add db -- npx -y @modelcontextprotocol/server-postgres` |
| **Файловая система** | Продвинутые операции с файлами | Сложные задачи с файлами | Локальная | `claude mcp add fs -- npx -y @modelcontextprotocol/server-filesystem` |
| **Slack** | Командное общение | Уведомления, обновления | Проект | Настройте в настройках |
| **Google Docs** | Доступ к документам | Правка и ревью документов | Проект | Настройте в настройках |
| **Asana** | Управление проектами | Учёт задач | Проект | Настройте в настройках |

## Хуки

Событийная автоматизация, которая выполняет команды оболочки на событиях Claude Code.

### События хуков

| Событие | Описание | Когда срабатывает | Сценарии |
|-------|-------------|----------------|-----------|
| `SessionStart` | Сессия начинается или возобновляется | Инициализация сессии | Задачи настройки |
| `Setup` | Настройка репозитория или прогон обслуживания | Только с `--init-only` либо с `--init`/`--maintenance` вместе с `-p` | Подготовить инструменты, установить зависимости |
| `InstructionsLoaded` | Инструкции загружены | Загружен CLAUDE.md или файл правил | Своя обработка инструкций |
| `UserPromptSubmit` | До обработки промпта (и, с v2.1.299, до раскрытия навыка или пользовательской команды) | Пользователь отправляет сообщение | Проверка ввода |
| `UserPromptExpansion` | Введённая слэш-команда (навык, пользовательская команда или промпт MCP) раскрывается в промпт | После `UserPromptSubmit`, до того как раскрытый промпт дойдёт до Claude | Блокировать прямой вызов `/command`, добавлять контекст навыка, журналировать команды |
| `PreToolUse` | До выполнения инструмента | До запуска любого инструмента | Проверка, журналирование |
| `PermissionRequest` | Показан диалог разрешения | Перед чувствительными действиями | Свои сценарии одобрения |
| `PermissionDenied` | Пользователь отклоняет запрос разрешения | После отклонения разрешения | Журналирование, аналитика, применение политики |
| `PostToolUse` | После успешной работы инструмента | После завершения любого инструмента | Форматирование, уведомления |
| `PostToolUseFailure` | Выполнение инструмента завершается ошибкой | После ошибки инструмента | Обработка ошибок, журналирование |
| `PostToolBatch` | После завершения пакета вызовов инструментов | Конец пакета инструментов | Сводные отчёты, пакетная проверка |
| `Notification` | Уведомление отправлено | Claude отправляет уведомление | Внешние оповещения |
| `MessageDisplay` | Текст сообщения ассистента отображается | Пока сообщение отрисовывается | Изменить или скрыть отображаемый текст |
| `SubagentStart` | Субагент запущен | Задача субагента начинается | Инициализировать контекст субагента |
| `SubagentStop` | Субагент завершает работу | Задача субагента выполнена | Цепочка действий |
| `Stop` | Claude заканчивает ответ | Ответ завершён | Очистка, отчёт |
| `StopFailure` | Ошибка API завершает ход | Происходит ошибка API | Восстановление после ошибки, журналирование |
| `TeammateIdle` | Агент-участник простаивает | Координация команды агентов | Распределить работу |
| `TaskCompleted` | Задача отмечена выполненной (срабатывает, только когда инструменты todo включены — см. [Хуки](06-hooks/README.md#события-хуков)) | Задача выполнена | Обработка после задачи |
| `TaskCreated` | Задача создана через TaskCreate (срабатывает, только когда инструменты todo включены — см. [Хуки](06-hooks/README.md#события-хуков)) | Создана новая задача | Учёт задач, журналирование |
| `ConfigChange` | Конфигурация обновлена | Настройки изменены | Реакция на изменения конфигурации |
| `CwdChanged` | Рабочий каталог меняется | Каталог изменён | Настройка под конкретный каталог |
| `DirectoryAdded` | Новый рабочий каталог зарегистрирован в середине сессии | `/add-dir` или `register_repo_root` в SDK | Настроить инструменты для нового каталога |
| `FileChanged` | Отслеживаемый файл изменился | Файл изменён | Наблюдение за файлами, пересборка |
| `PreCompact` | До операции сжатия | Сжатие контекста | Сохранение состояния |
| `PostCompact` | После завершения сжатия | Сжатие выполнено | Действия после сжатия |
| `PreModelSwitch` | До применения запрошенной смены модели | Запрошена смена модели | Пропустить или отклонить смену модели |
| `PostModelSwitch` | После смены модели сессии | Смена модели завершена | Записать или отреагировать на смену модели |
| `WorktreeCreate` | Worktree создаётся | Создан Git worktree | Настроить окружение worktree |
| `WorktreeRemove` | Worktree удаляется | Git worktree удалён | Очистить ресурсы worktree |
| `Elicitation` | MCP-сервер запрашивает ввод | Запрос ввода MCP | Проверка ввода |
| `ElicitationResult` | Пользователь отвечает на запрос ввода | Пользователь отвечает | Обработка ответа |
| `SessionEnd` | Сессия завершается | Завершение сессии | Очистка, сохранение состояния |

## Файлы памяти

Постоянный контекст, который загружается сам между сессиями.

### Типы памяти

| Тип | Расположение | Область | Когда использовать |
|------|----------|-------|-------------|
| **Управляемая политика** | Политики организации | Организация | Применять стандарты на всю организацию |
| **Проект** | `./CLAUDE.md` | Проект (команда) | Стандарты команды, контекст проекта |
| **Правила проекта** | `.claude/rules/` | Проект (команда) | Модульные правила проекта |
| **Пользователь** | `~/.claude/CLAUDE.md` | Пользователь (личная) | Личные предпочтения |
| **Правила пользователя** | `~/.claude/rules/` | Пользователь (личная) | Модульные личные правила |
| **Локальный** | `./CLAUDE.local.md` | Локальная (в gitignore) | Локальные переопределения для конкретной машины (в gitignore). Описан на https://code.claude.com/docs/en/memory как поддерживаемый файл переопределений для разработчика. |

## Матрица краткого справочника

### Руководство по выбору функции

| Задача | Рекомендуемая функция | Почему |
|------|---------------------|-----|
| Быстрое сокращение | Слэш-команда | Вручную, сразу |
| Постоянный контекст | Память | Загружается сама |
| Сложная автоматизация | Навык | Вызывается сама |
| Специализированная задача | Субагент | Изолированный контекст |
| Внешние данные | MCP-сервер | Доступ в реальном времени |
| Автоматизация по событиям | Хук | Срабатывает на событие |
| Готовое решение | Плагин | Всё в одном наборе |

### Приоритет установки

| Приоритет | Функция | Команда |
|----------|---------|---------|
| 1. Необходимое | Память | `cp 02-memory/project-CLAUDE.md ./CLAUDE.md` |
| 2. На каждый день | Слэш-команды | `cp 01-slash-commands/*.md .claude/commands/` |
| 3. Качество | Субагенты | `cp 04-subagents/*.md .claude/agents/` |
| 4. Автоматизация | Хуки | `cp 06-hooks/*.sh ~/.claude/hooks/ && chmod +x ~/.claude/hooks/*.sh` |
| 5. Внешнее | MCP | `claude mcp add github -- npx -y @modelcontextprotocol/server-github` |
| 6. Продвинутое | Навыки | `cp -r 03-skills/* ~/.claude/skills/` |
| 7. Полное | Плагины | `claude --plugin-dir ./07-plugins/pr-review` |

## Полная установка одной командой

Установите все примеры из этого репозитория:

```bash
# Создайте каталоги
mkdir -p .claude/{commands,agents,skills} ~/.claude/{hooks,skills}

# Установите все функции
cp 01-slash-commands/*.md .claude/commands/ && \
cp 02-memory/project-CLAUDE.md ./CLAUDE.md && \
cp -r 03-skills/* ~/.claude/skills/ && \
cp 04-subagents/*.md .claude/agents/ && \
cp 06-hooks/*.sh ~/.claude/hooks/ && \
chmod +x ~/.claude/hooks/*.sh
```
