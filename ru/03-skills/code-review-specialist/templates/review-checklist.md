# Чек-лист код-ревью

## Чек-лист по безопасности
- [ ] Нет зашитых учётных данных и секретов
- [ ] Проверка ввода для всех пользовательских данных
- [ ] Защита от SQL-инъекций (параметризованные запросы)
- [ ] Защита от CSRF для операций, меняющих состояние
- [ ] Защита от XSS с правильным экранированием
- [ ] Проверки аутентификации на защищённых эндпоинтах
- [ ] Проверки авторизации для ресурсов
- [ ] Безопасное хеширование паролей (bcrypt, argon2)
- [ ] Нет чувствительных данных в логах
- [ ] Принудительный HTTPS

## Чек-лист по производительности
- [ ] Нет запросов N+1
- [ ] Индексы используются там, где нужно
- [ ] Кэширование там, где оно полезно
- [ ] Нет блокирующих операций в главном потоке
- [ ] Async/await используется правильно
- [ ] Большие наборы данных разбиты на страницы
- [ ] Соединения с базой берутся из пула
- [ ] Регулярные выражения оптимизированы
- [ ] Нет лишнего создания объектов
- [ ] Утечки памяти предотвращены

## Чек-лист по качеству
- [ ] Функции короче 50 строк
- [ ] Понятные имена переменных
- [ ] Нет дублирующегося кода
- [ ] Корректная обработка ошибок
- [ ] Комментарии объясняют ЗАЧЕМ, а не ЧТО
- [ ] Нет console.log в продакшене
- [ ] Проверка типов (TypeScript/JSDoc)
- [ ] Принципы SOLID соблюдены
- [ ] Паттерны проектирования применены правильно
- [ ] Самодокументируемый код

## Чек-лист по тестированию
- [ ] Написаны модульные тесты
- [ ] Покрыты граничные случаи
- [ ] Проверены сценарии ошибок
- [ ] Есть интеграционные тесты
- [ ] Покрытие тестами > 80%
- [ ] Нет нестабильных тестов
- [ ] Внешние зависимости замокированы
- [ ] Понятные имена тестов
